# Loafer — The First Law Firm for AI Agents

Parody YC-style landing page. Vite + Tailwind v4.

## Run locally

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173`

## Build for production

```bash
npm run build
npm run preview
```

## Stack

- Vite 7
- Tailwind CSS 4
- Google Fonts (DM Serif Display + Inter)
- Zero frameworks, vanilla JS

---

*Parody concept for a fictional YC application video. Not a real law firm.*
